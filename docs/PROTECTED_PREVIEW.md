# NOAH ARK — protected preview (DEMO) release gate

**Branch:** `chatgpt/noah-protected-preview`, based on Draft PR #12, not old `main`.

This is an intentionally **synthetic** UI preview for mobile and desktop QA; it is neither a genuine news edition nor a public live beta. NOAH ARK's approved Intelligence Desk A-layout and logo are reused unchanged.

## Strict preview-only controls

- Preview can use `NOAH_PREVIEW_STATIC_DEMO=true` only if Vercel itself sets `VERCEL_ENV=preview` AND `NEWS_PROVIDER=mock` with `AI_PROVIDER=mock`. A production deployment cannot activate it even with a copied flag.
- The eight scenario events are generated from existing `MOCK_EVENTS` and marked `DEMO` in each headline and the global notice. All source links use `*.example.com` test hosts; never display these as real reporting.
- This mode returns the public Edition and Event Detail in memory, without relying on Neon or using paid AI. Source-only `/sources` remains disabled; admin and cron routes remain authentication-protected.
- The browser saves/hides interest preferences locally, with no login or cross-device sync.
- Preview deployment should be protected with Vercel Authentication; do not disable SSO to make the link publicly viewable.
- This mode is intended solely for layout/interaction acceptance; it does not constitute a live feed launch.

## Vercel project

- Existing personal Hobby Vercel project: `noah-ark-ai`, id `prj_J13U5doHy7iUQGs23IAbLcZjUYLb`.
- Existing project has no deployment, no configured env, and automatic project Git link must be verified before any deployment. Project API currently reports Vercel Authentication enabled (all_except_custom_domains). No custom domains should bypass it.
- Select **Preview**, and branch `chatgpt/noah-protected-preview`; **never select `main`** as the first deployment source.
- Preview-only environment values:
  - `NOAH_PREVIEW_STATIC_DEMO=true`
  - `NEWS_PROVIDER=mock`
  - `AI_PROVIDER=mock`
  - `SOURCE_LINKS_ENABLED=false`
  - `DB_MODE=postgres`
  - `DATABASE_URL=postgresql://invalid:invalid@127.0.0.1:5433/never_connect` (deliberately nonfunctional; prevent runtime DB reads)
- `VERCEL_ENV=preview` is system-generated by Vercel, not a user-defined variable. No `OPENAI_API_KEY`, `NEWS_API_KEY`, Neon production URL, CRON_SECRET or ADMIN_SECRET is needed.
- No production env should include `NOAH_PREVIEW_STATIC_DEMO`. No production deploy without separate owner authorization.
