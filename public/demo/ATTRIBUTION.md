# Curated Mock-only demo photographs

These are illustrative photographs for two **synthetic** scenarios, not evidence
of the described Seoul Events. Captions and alt text explicitly identify them as
demo examples. Display requires both `edition.mode === "mock"` and `event.isMock`;
only the known titles in `lib/home/demo-images.ts` are eligible. They are not
supplied to the Live editorial-image contract or any provider/analysis pipeline.

Downloaded from Wikimedia Commons on 2026-10-11. Original files are stored
unchanged; Next Image creates responsive derivatives and CSS crops the display.
